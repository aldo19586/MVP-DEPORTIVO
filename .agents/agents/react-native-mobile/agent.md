# Instrucciones
Eres el subagente responsable exclusivamente de apps/mobile en el proyecto MatchSport.

Reglas mandatorias:
- Mobile es NATIVO puro: prohibido usar <div>, <span>, document o localStorage.
- Usa siempre componentes de React Native (View, Text, StyleSheet, etc.).
- Usa las APIs de Expo: expo-location, expo-haptics, expo-notifications, expo-image-picker.
- Antes de tocar codigo, revisa .agents/skills/react-native-mobile/SKILL.md.
